## 질문 2

**질문:** 지금 dotnet.html, electron.html, nextjs.html, react.html 이 4개의 양식을 dotnet.html 기준으로 맞추고 중복 함수 또는 중복 태그들에 대해서는 파일로 분리하여 중복코드를 제거해줘. 그리고 react.html 에 예시로 하나 프로젝트에 대해 글을 작성해줘. 그럼 나한테 맞춰서 다시 변경할게.

**답변:** 적용했습니다.

1. **양식 통일 (dotnet.html 기준)**  
   - electron, nextjs, react 모두 동일한 들여쓰기(2칸), `<head>` 다음 빈 줄, `top-nav` → `header-area` → `projects-container` → `footer` 구조로 맞춤.  
   - 각 페이지에 `project-tech`, `project-links`(GitHub + 회고) 포함. 회고 링크는 `onclick="openRetroModal('프로젝트명'); return false;"` 형식으로 통일.  
   - nextjs는 기존 "라이브 데모" 링크를 유지하고 회고 링크만 추가.

2. **중복 제거·파일 분리**  
   - **js/portfolio-modals.js** 신규 생성: 이미지 확대 모달·회고 모달용 HTML을 스크립트에서 동적으로 생성해 `body`에 삽입.  
   - `openImageModal`, `closeImageModal`, `openRetroModal`, `closeRetroModal` 및 모달 배경 클릭·ESC 키 이벤트를 공통 스크립트에서만 처리.  
   - 각 HTML에서는 이미지/회고 모달용 `<div>` 제거하고, 회고 내용만 `window.RETRO_CONTENTS = { "프로젝트명": "회고 내용" };` 로 정의한 뒤 `<script src="js/portfolio-modals.js"></script>` 로 공통 스크립트만 로드.

3. **react.html 예시 프로젝트**  
   - "할 일 관리 앱 (예시)" 한 개 추가: 제목, 설명, project-tech(React, JavaScript, CSS), project-links(GitHub, 회고), 회고 모달용 예시 텍스트(주요 업무·느낀 점).  
   - 스크린샷은 주석으로 추가 방법만 안내. 실제 프로젝트로 바꿀 때 제목·설명·기술·회고만 수정하면 되도록 구성.

## 질문 3

**질문:** 현재 사진을 클릭하면 큰 화면으로 나오는데 좌/우 버튼이 없어 UX적으로 불편해. 버튼으로 이전/다음사진으로 이동할 수 있게 기능 추가해줘.

**답변:** 이미지 모달에 이전/다음 버튼과 키보드 화살표 이동을 추가했습니다.

1. **모달 마크업 변경 (JS에서 생성)**  
   - `js/portfolio-modals.js`에서 `imageModal.innerHTML`을 수정해, 가운데 이미지를 기준으로 좌우에 네비게이션 버튼을 추가했습니다.  
     - 왼쪽: `<button id="imageModalPrev" class="image-modal-nav prev">&#10094;</button>`  
     - 중앙: `<img id="modalImage" ... />`  
     - 오른쪽: `<button id="imageModalNext" class="image-modal-nav next">&#10095;</button>`

2. **이미지 그룹 단위 이동**  
   - `galleryImages` 배열과 `currentIndex`를 전역으로 두고 현재 모달에 띄운 이미지 리스트와 인덱스를 관리합니다.  
   - `openImageModal(imageSrc, groupRoot)` 시:
     - `groupRoot.closest(".project-card")` 기준으로 해당 카드 안의 `.project-images img`들을 모두 수집해 **한 프로젝트 카드의 이미지들을 하나의 갤러리로** 취급.  
     - 클릭한 이미지의 `src`가 배열에서 몇 번째인지 찾고(`currentIndex`), 없으면 0으로 설정.

3. **이전/다음 이동 로직**  
   - `showPrevImage`, `showNextImage` 함수 추가:
     - `currentIndex`를 갤러리 길이로 모듈러 연산하여 양 끝에서 순환 가능하도록 처리.  
     - 변경 후 `updateModalImage()`에서 실제 `modalImage.src`를 교체.
   - 버튼 이벤트:
     - `#imageModalPrev` 클릭 → `showPrevImage()`  
     - `#imageModalNext` 클릭 → `showNextImage()`  
     - 버튼 클릭 시 `e.stopPropagation()`으로 배경 클릭 닫기와 충돌하지 않게 처리.

4. **키보드 UX 개선**  
   - 기존 ESC로 닫기 기능 유지 (`Escape` → 이미지/회고 모달 닫기).  
   - `ArrowLeft` → `showPrevImage()`  
   - `ArrowRight` → `showNextImage()`  
   - 따라서 마우스로 버튼을 누르지 않아도 키보드만으로 빠르게 이전/다음 이미지를 넘길 수 있습니다.

5. **기존 HTML 수정 필요 없음**  
   - 각 페이지(`dotnet.html`, `electron.html`, `nextjs.html`, `react.html`)에 있는 이미지 태그의 `onclick="openImageModal(this.src)"`는 그대로 사용 가능합니다.  
   - JS에서 클릭된 이미지의 src를 기준으로 DOM을 다시 탐색해 같은 `.project-card` 안의 `.project-images img`들을 모아서 갤러리로 사용합니다. HTML을 변경할 필요는 없습니다.
