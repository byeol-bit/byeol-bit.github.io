Q: 회고는 누르면 모달형식으로 내용을 보여주게끔 수정해줘. 그리고 지금 default는 못누르게하고 회색인데, 회고가 활성화되었을때의 타입도 필요해.
A: projects.ts 에 ProjectLink 타입에 "retrospect" 타입과 Project 타입에 retrospectiveLines 필드를 추가하고, "기상 분석 프로그램" 프로젝트의 links 중 회고 링크의 type 을 "retrospect" 로 바꾼 뒤, ProjectList 컴포넌트에서 type 이 "retrospect" 인 링크는 버튼으로 렌더링해 클릭 시 회고 내용을 보여주는 모달을 띄우도록 구현했다. 또한 index.css 에 project-link-retro 와 회고 모달 스타일을 추가해, 기본 default 타입은 회색/비활성, 회고 타입은 따뜻한 강조 색상과 함께 클릭 가능한 버튼으로 보이도록 했다.

Q: @app/src/pages/ReactProjectsPage.tsx 에서는 사진을 클릭해도 다른 페이지들처럼 사진이 크게 보이고 좌우로 이동할 수 있는 동작이 안되고있어. 적용시켜줘.
A: ReactProjectsPage 에서 ProjectList 에 전달하던 enableGallery={false} 를 제거했다. 기본값이 true 이므로 DotnetPage, ElectronPage, NextjsPage 와 동일하게 이미지 클릭 시 갤러리(크게 보기, 좌우 이동)가 동작한다.

Q: app/public/react폴더 안의 내용들이 dist에 생겨야하는데 안생기고 있어. 어떻게 해야해?
A: Vite에서는 public 폴더의 파일이 dist 루트(/) 기준으로 복사되므로, projects.ts 안에서 이미지 경로를 ./public/... 이 아니라 /dotnet/..., /electron/..., /nextjs/..., /react/... 형태로 쓰도록 수정했다. 예를 들어 React 프로젝트 이미지는 /react/first-project/page-1.png 와 같이 변경했고, 이렇게 하면 빌드 시 해당 경로로 요청될 때 public/react/... 에 있는 실제 파일이 dist 로 복사되어 정상적으로 제공된다.

Q: 지금 @my_charactor.jpg 이나 다른 현제 루트폴더에 있는 이미지들이 안보이는 현상은 왜그래? 이것도 최신 dist폴더에 있는 이미지가 아닌 기존 이미지를 사용해서그래? 이미지는 바뀐게 없어. 모두 변경해줘.
A: HomePage.tsx, ProjectPageLayout.tsx, index.css, projects.ts 등에서 이미지를 /public/... 경로로 참조하고 있었기 때문에 정적 배포 환경(GitHub Pages)에서는 404가 나고 보이지 않았다. 모든 이미지/아이콘 경로를 /public/... 대신 /my_charactor.jpg, /fa-*.png, /dotnet/..., /electron/..., /nextjs/..., /react/... 처럼 루트 기준(/) 경로로 통일해 수정하여, public 폴더의 실제 파일들과 일치하도록 변경했다.

Q: DOM Path: div#root > main.container > div.top-nav fade-in-up > div.top-nav-right > button 버튼을 클릭하면 다크모드/라이트모드가 되게끔 수정해줘. 그리고 지금 내 캐릭터가 안보이는데 왜 안보이는지도 확인해줘.
A: HomePage.tsx 에서 상단 우측 버튼에 onClick 핸들러(toggleTheme)를 연결하고, useState 로 isDarkMode 상태를 관리하며 document.documentElement 에 theme-dark 클래스를 토글하도록 구현했다. index.css 에 html.theme-dark body 및 주요 카드/텍스트 색상에 대한 다크모드 스타일을 추가해 버튼 클릭 시 다크/라이트 모드가 전환되도록 했다. 또한 프로필 이미지 경로가 실제 파일명(one-hundred-percent-attached-character.png)과 다르게 작성되어 있었기 때문에 src 를 /one-hundred-percent-attached-character.png 로 수정해 캐릭터가 정상적으로 보이도록 했다.

Q: 다크모드 버튼은 다른 페이지들에도 존재해. 모든 페이지에서 클릭이 가능하게 해주고 중복 되는 부분이 있으면 컴포넌트화 해서 구현하도록 해.
A: 다크모드 토글 로직을 components/ThemeToggleButton.tsx 로 분리해 useState + useEffect 로 theme 상태를 관리하고, document.documentElement 에 theme-dark 클래스를 토글하며 localStorage('theme') 에 저장하도록 했다. HomePage.tsx 와 ProjectPageLayout.tsx 상단 우측 버튼을 모두 ThemeToggleButton 컴포넌트를 사용하도록 교체하여, 홈과 .NET/Electron/Next.js/React 프로젝트 페이지 등 모든 페이지에서 동일한 다크모드 토글 버튼이 동작하도록 중복 코드를 제거했다.
