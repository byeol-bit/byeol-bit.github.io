Q: @app/src/pages/HomePage.tsx 의 각 <div className="stats-content"> 태그들을 @app/src/data/projects.ts 의 프로젝트 내용 갯수로 표시하자.
A: HomePage.tsx 에서 projects.ts 의 dotnetProjects, electronProjects, reactProjects, nextjsProjects 배열을 import 한 뒤, 각 스택별 카드의 <div className="stats-content"> 내부를 하드코딩된 숫자 대신 {dotnetProjects.length}, {electronProjects.length}, {reactProjects.length}, {nextjsProjects.length} 로 변경하여 프로젝트 개수에 맞게 자동으로 표시되도록 수정했다.

Q: @app/src/data/projects.ts 의 title로 "기상 분석 프로그램"에 회고를 넣으려고 해. 어떻게 하면 되는지 예시로 하나 달아줘.
A: "기상 분석 프로그램" 프로젝트 객체의 links 배열 안에 { label: "회고", href: "https://example.com/retrospective", external: true, type: "default" } 와 같이 href(회고 글 주소)와 external: true 를 포함한 링크 객체를 추가하면 된다.

Q: 회고는 누르면 모달형식으로 내용을 보여주게끔 수정해줘. 그리고 지금 default는 못누르게하고 회색인데, 회고가 활성화되었을때의 타입도 필요해.
A: projects.ts 에 ProjectLink 타입에 "retrospect" 타입과 Project 타입에 retrospectiveLines 필드를 추가하고, "기상 분석 프로그램" 프로젝트의 links 중 회고 링크의 type 을 "retrospect" 로 바꾼 뒤, ProjectList 컴포넌트에서 type 이 "retrospect" 인 링크는 버튼으로 렌더링해 클릭 시 회고 내용을 보여주는 모달을 띄우도록 구현했다. 또한 index.css 에 project-link-retro 와 회고 모달 스타일을 추가해, 기본 default 타입은 회색/비활성, 회고 타입은 따뜻한 강조 색상과 함께 클릭 가능한 버튼으로 보이도록 했다.

Q: @app/src/pages/ReactProjectsPage.tsx 에서는 사진을 클릭해도 다른 페이지들처럼 사진이 크게 보이고 좌우로 이동할 수 있는 동작이 안되고있어. 적용시켜줘.
A: ReactProjectsPage 에서 ProjectList 에 전달하던 enableGallery={false} 를 제거했다. 기본값이 true 이므로 DotnetPage, ElectronPage, NextjsPage 와 동일하게 이미지 클릭 시 갤러리(크게 보기, 좌우 이동)가 동작한다.

Q: app/public/react폴더 안의 내용들이 dist에 생겨야하는데 안생기고 있어. 어떻게 해야해?
A: Vite에서는 public 폴더의 파일이 dist 루트(/) 기준으로 복사되므로, projects.ts 안에서 이미지 경로를 ./public/... 이 아니라 /dotnet/..., /electron/..., /nextjs/..., /react/... 형태로 쓰도록 수정했다. 예를 들어 React 프로젝트 이미지는 /react/first-project/page-1.png 와 같이 변경했고, 이렇게 하면 빌드 시 해당 경로로 요청될 때 public/react/... 에 있는 실제 파일이 dist 로 복사되어 정상적으로 제공된다.
